0. 座標系と共通ルール
--------------------------------------------------------------------------------
- スライドサイズ: 16:9 = 13.333 x 7.5 inch = 960 x 540 pt。本書の座標・寸法は
  すべて pt、原点は左上。python-pptx では Pt() でそのまま指定できる。
- 画像はすべて docs/final-presentation/assets/ 配下。等比でのみ拡縮する
  (非等比変形・再着色・回転は禁止)。
- SVG 正本は assets/src/。再生成は `rsvg-convert -z 2 src/X.svg -o X.png`
  (背景3種のみ -z 1)。

1. アートディレクション「INK & MINT」
--------------------------------------------------------------------------------
方向: アプリ UI をそのままスライドへ拡張する。「紙のカードがインクの土台の上に
浮いている」というアプリの視覚文法(太いインク輪郭 / 右下オフセットの土台 /
ミントのアクセント / ピル+ルールのヘッダ)を、スライドの構造そのものにする。
テンプレ感のあるグラデーション・影・立体アイコンは一切使わない。影は常に
「ベタ塗りインクのオフセット土台」で表現する。

トーン: 遊び心はあるが、審査用として構造は厳格。1スライド=1メッセージ。
余白を多く、要素は少なく、輪郭は太く。

3. タイポグラフィ
--------------------------------------------------------------------------------
- 欧文: Avenir Next(見出し Bold + さらに太く見せたい所は Heavy 相当で bold指定、
  本文 Medium)。無い環境では Arial。
- 和文(S4の例文など最小限): Hiragino Sans(見出し W8 / 本文 W5)。
- 数字はできるだけ等幅設定(スライド番号・時間表記)。

スケール(pt):
  D1 タイトルスライド題字  54  bold   字間 -1%
  D2 スライドタイトル      26  bold   行送り 1.15(最大2行。1行なら28へ拡大可)
  D3 セクション/カード見出し 18 bold
  D4 本文                  14         行送り 1.3
  D5 チップ/リスト         12.5-13
  D6 ピル/キャプション     11  bold   大文字+字間 +8%(kicker)
最小フォントは 11pt。これ未満を作らない。

4. 視覚文法(再利用コンポーネント)
--------------------------------------------------------------------------------
[Card] 紙カード
  角丸 12pt(大カードは 16pt)、輪郭 ink 2.5pt(ヒーローは 3pt)。
  土台: 同形状を +4pt/+5pt(右/下)へ複製し ink でベタ塗り、最背面に置く。
  ※土台のオフセット方向は全スライドで右下に統一。

[Chip] 小カード・リスト行
  角丸 8pt、輪郭 ink 1.75pt、土台オフセット +2.5pt/+3pt。

[Pill] ラベル
  完全角丸、高さ 24-28pt、輪郭 ink 1.75pt、左右パディング 12pt。
  種類: kicker(ink面+白文字) / 番号(白面+ink文字) / タグ(トーン面+ink文字)。

[Header] コンテンツスライド共通ヘッダ(S2-S9, A1, A2)
  y=40 に配置: kickerピル(x=60) + ink 2.5pt の水平ルール(ピル右端+12pt から
  x=856 まで、垂直中央) + 番号ピル(右端 x=900 に右揃え、幅44、"02" 等の2桁)。
  ルールは線でなく高さ2.5ptの矩形で描くと確実。
  スライドタイトル(D2)は x=60, y=78, 幅840。リード文(D4 mutedInk)は
  タイトル下 8pt。

[Screenshot frame] 実機スクショ(1290x2796)の額装
  角丸 20pt で画像をクロップ(PPTXの角丸図形塗りつぶし or 角丸マスク)、
  輪郭 ink 3pt、土台 +4pt/+5pt。標準幅 150pt(高さ自動で約325pt)。
  ラベルはフレーム下 8pt に mint タグピル(高さ24、11pt bold)を中央揃え。

[Waveform] アクセント
  waveform-motif.png(ミントの5本バー)。飾りは1スライド1個まで。

7. スクリーンショット運用の注意(QA向け)
--------------------------------------------------------------------------------
a) 内容: 現在の 05-phrases / 08-notes には個人的な独り言(Claude/GPT/AGM-SG
   への言及など)がそのまま写っている。審査で読まれる前提なら、S4 の例文
   (カフェ/プロジェクト)を実際にアプリへ入力した状態で全シート撮り直すと、
   スライド間で例文が一気通貫になり完成度が上がる。撮り直せない場合は
   そのまま使用可(機微情報ではない)が、ユーザーに一言確認を推奨。
b) 統一: ステータスバーの時刻・バッテリーが揃った同一セッションで撮るのが
   理想。ライトモード・原文タブなど表示状態も揃える。
c) 加工禁止: ぼかし・トリミング(角丸クロップ以外)・拡大縮小の非等比は
   しない。額装(ink輪郭+土台)だけで十分ブランドに乗る。
